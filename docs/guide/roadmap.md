# Roadmap

`VitePress Blog` is meant to stay lightweight, practical, and easy to extend. The goal is not to turn VitePress into a complex CMS, but to make blog-oriented sites feel complete out of the box.

## Current Direction

The main areas of focus are:

- `vitepress-blog-init`
  Make it faster to start a new blog or add blog features to an existing VitePress site.
- Easily replaceable components
  Keep theme pieces modular so you can swap or customize layouts without fighting the default structure.
- Giscus integration
  Provide a simple path to comments without forcing a heavyweight discussion system into every site.

## Philosophy

When new features are added, the theme should continue to favor:

- Markdown-first authoring
- a small and understandable configuration surface
- compatibility with the default VitePress workflow
- easy customization over locked-in abstractions

If you have a feature request that fits those goals, contributions and suggestions are welcome.
